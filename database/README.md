# Схема MySQL

`schema.sql` используется приложением и служит файлом схемы для проверки в MySQL Workbench.

В Workbench выберите **File → Import → Reverse Engineer MySQL Create Script**, откройте `schema.sql` и оставьте включённым создание EER Diagram. Откроется модель с таблицами и внешними ключами. Модель можно сохранить как `.mwb`.

`products.order_id` связывает продукт с одним приходом. `product_prices` хранит отдельную цену для каждой валюты. Удаление прихода каскадно удаляет его продукты и цены. Пользователи нужны только для демонстрации JWT-входа; управления учётными записями в интерфейсе нет.

Суммы указаны в минимальных единицах валюты, например `10025` означает `100.25`. Конвертации USD в UAH нет. Даты создания хранятся в UTC, гарантийные даты — как `DATE`.
